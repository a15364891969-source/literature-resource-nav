# 文献资料查询资源导航 Demo
> 原生前端小原型，使用 HTML / CSS / JavaScript + ECharts 开发，响应式布局。

## ✨ 功能
1. 分类标签筛选资源条目
2. 关键词搜索过滤
3. ECharts 条形统计图表，可视化资源分类分布
4. 适配PC、手机的响应式布局
5. 空状态提示、CSS变量主题系统

本项目**无后端服务**，全部数据为Mock，写在前端JS内，属于交互原型演示。

## 🛠 技术栈
- HTML5 + CSS3（CSS变量、Media Query响应式）
- 原生JavaScript，手写渲染与筛选逻辑
- ECharts 5.5.0（CDN引入）

下载 index.html，双击在浏览器打开，需要联网加载ECharts图表库。
